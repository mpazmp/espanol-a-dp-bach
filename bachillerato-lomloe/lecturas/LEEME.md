# Lecturas obligatorias · 2º Bachillerato

Itinerarios de lectura y simulacros de la pregunta 5b de la PEvAU (Anexo III de las orientaciones 2026-27).

## Estructura

```
bachillerato-lomloe/
└── lecturas/
    ├── index.html                  ← portada con las cuatro obras
    ├── LEEME.md                    ← este archivo
    ├── arbol-de-la-ciencia/
    │   └── index.html              ← Baroja (publicado)
    ├── la-realidad-y-el-deseo/     ← Cernuda (pendiente)
    ├── la-casa-de-bernarda-alba/   ← Lorca (pendiente)
    └── el-cuarto-de-atras/         ← Martín Gaite (pendiente)
```

## Reglas para cada libro nuevo

1. **Una carpeta por obra**, con el título en minúsculas, sin tildes y con guiones (`la-casa-de-bernarda-alba`).
2. **Dentro, un único archivo `index.html`.** Así la dirección queda limpia: `.../lecturas/la-casa-de-bernarda-alba/`.
3. **Prefijo de autoguardado propio** en el código de cada página (`arbol-2b-`, `bernarda-2b-`, `cernuda-2b-`, `cuarto-2b-`), para que las respuestas de un libro no pisen las de otro.
4. **Activar el libro en la portada**: en `lecturas/index.html`, cambiar `url: null` por `url: 'nombre-de-la-carpeta/'`.
5. **Solo material para las alumnas.** La guía de la profesora (claves, respuestas modelo, prueba final) y los Word no se suben a GitHub: el repositorio es público. Van a Drive, restringidos al dominio Attendis.
6. **Citas breves.** Las obras tienen derechos vigentes: nada de capítulos o poemas completos en páginas públicas.
